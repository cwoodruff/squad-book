# Part IV — Looking Ahead: Squad 2.0 (Preview) {.unnumbered}

Part IV looks ahead to Squad 2.0. Unlike the rest of the book, it targets **Squad v2.0.0-preview.2** (the `insider` channel, with `preview` as an alias), so everything here is preview material and may change before a stable release. It explains what changed, how one team works across several AI clients, how host projections and capability negotiation work, the new state boundary, and how to upgrade. It comes after the v1.1.0 material so you can compare the two directly.

Read it to evaluate 2.0 or to plan a migration; you can skip it entirely if you stay on v1.1.0. Install the preview channel only in a scratch directory (see Volume 1, Chapter 2). Appendix H is the feature matrix for this part.

- **Chapter 18: Squad 2.0: What Changed and Why** The overview.
- **Chapter 19: Using Squad Across Clients** Working in each supported host.
- **Chapter 20: Host Projections, Client Adapters, and Capability Negotiation** How one team is projected into many hosts.
- **Chapter 21: The State MCP Boundary, Runtime Upstreams, and the Experimental Backend** State in 2.0.
- **Chapter 22: Upgrading to Squad 2.0 and the Road Ahead** Migration and what is next.

**Tasktrack:** you project your existing Tasktrack team into other clients on a scratch copy; your main project stays on v1.1.0.
