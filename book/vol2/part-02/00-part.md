# Part II — Production Operations {.unnumbered}

Part II is about trusting Squad with real responsibility. You harden security, run in containers and the cloud, wire Squad into CI/CD and release, instrument it with observability, and prepare for failure with troubleshooting and disaster recovery. It follows Part I because operating well requires understanding state and coordination first.

Read it if you run Squad for a team, in automation, or in an environment with security and reliability expectations.

- **Chapter 6: Security Hardening** Threat model and controls.
- **Chapter 7: Containers, Cloud Hosting, and Deployment Modes** Running Squad off your laptop.
- **Chapter 8: CI/CD and Release** Automating builds and releases.
- **Chapter 9: Observability** Telemetry and monitoring.
- **Chapter 10: Troubleshooting and Disaster Recovery** Diagnosing problems and recovering.

**Tasktrack:** by the end of Part II Tasktrack has a hardened configuration, a container, a CI pipeline, telemetry, and a rehearsed disaster-recovery drill.
