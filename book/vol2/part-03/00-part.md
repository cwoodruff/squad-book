# Part III — Internals and Extension {.unnumbered}

Part III is for builders. Having operated Squad, you now look inside it: the architecture, the coordinator, and agent identity and provenance. You then extend it with the SDK, plugins, tools, and hooks, build autonomous and resilient agents, and study the formal specification. It sits after operations so the internals explain behavior you have already seen.

Read it if you want to debug deeply, write extensions, or contribute. Keep Appendix G (SDK API) and Appendix I (Specification Cheat Sheet) nearby.

- **Chapter 15: Plugins, Extensions, Tools, and Hooks** Extending behavior.
- **Chapter 16: Building Autonomous and Resilient Agents** Long-running agent design.
