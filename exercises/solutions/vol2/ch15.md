# Chapter 15 Solutions

## Exercise Solutions

1. **Classification:** A code-review rubric belongs in team configuration if unique to this team, or in a plugin if other teams will reuse it. A company-wide routing mode changes core coordinator behavior and should be proposed to maintainers. A repository-specific branch convention belongs in this team's `.squad/` guidance. An Azure deployment knowledge pack is a plugin if reusable. A new reviewer-enforcement rule that must apply globally may require a core RFC; if it is only a local policy and the existing hook/session integration can enforce it, keep it in team/host configuration.

2. A valid manifest needs `id`, `name`, `version`, and a non-empty `files` array. Put the knowledge and ceremony assets under the plugin folder, declare the corresponding component kinds, and map each `source` to a relative target under an approved `.squad/` root. `repository.url` is recorded and displayed. `copilot.requires` identifies an optional Copilot plugin dependency and may include a version and reason. Squad deploys only the declared static files; it does not fetch the repository, install the Copilot plugin, or execute metadata commands.

3. Validate `taskId` against the API's ID format before constructing a request, use `AbortSignal.timeout()` or an equivalent bounded cancellation mechanism, and cap the response body before returning it to the model. A missing task should return a clear `resultType: 'failure'` result that says it was not found and should not be retried. A timeout or service-unavailable result should be a distinct failure category and be retried only by the caller's bounded retry policy. Do not return credentials, stack traces, or unbounded response content.

4. Register the modifying hook first and the blocking hook second. For example, the first can normalize a command argument, return `{ action: 'modify', modifiedArguments: { ... } }`, and the second can inspect the resulting command and block it. `runPreToolHooks()` passes modified arguments forward; if a hook returns `block`, later hooks do not run. The caller must pass the final allowed/modified arguments to the real tool and must prevent execution after a block.

5. Test each supported write tool (`edit`, `create`, `write_file`, `create_file`) with both `path` and `file_path`, and verify that read-only tools are not blocked as writes. Include missing/non-string paths, exact and nested matches, Windows separators, `*` versus `**`, and absolute paths. The implementation uses a simple glob-to-regex conversion and allows a recognized write attempt if the path is absent, so those edge cases need explicit assertions. This helper is not a filesystem sandbox: enforce process permissions, workspace roots, and symlink/path-resolution protections at the host or operating-system layer.

## Quiz Answers

1. A change to global coordinator routing belongs in Squad core and should go through the maintainers' RFC process.
2. No. `upstream.installCommand` is metadata for humans; Squad does not execute it.
3. `marketplace browse` lists top-level directories from a registered GitHub repository through authenticated `gh`. Plugin `install` deploys a plugin from a local directory after validating its manifest and static files. Browsing does not remotely fetch/install the selected directory.
4. The plugin must be installed and enabled, declare runtime capabilities, use a supported lifecycle event and capability type, name an approved provider, and provide safe output paths. (Any two of these conditions earn credit.)
5. `squad_route` needs host dependencies to create a real agent session. Without the fan-out dependency getter and required collaborators it returns a failure instead of claiming it dispatched work.
6. `HookPipeline` uses `action: 'allow' | 'block' | 'modify'` and `modifiedArguments`; a session `onPreToolUse` callback uses the adapter's permission fields such as `permissionDecision`, `modifiedArgs`, and `additionalContext`. They are different types and must be wired at their respective integration points.
7. The helper targets email-like strings only, can miss other sensitive data, and does not protect data that is logged or transmitted outside its post-tool result path. It is one transform, not a complete privacy control.
