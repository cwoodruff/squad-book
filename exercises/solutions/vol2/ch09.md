# Chapter 9 Solutions

## Exercise Solutions

1. A metric such as `squad.agent.duration` p95, segmented by stable service identity, can alert that latency is increasing. A trace from a slow run can reveal which instrumented operation consumed time, but only operations with spans are visible. Logs can show related runtime or exporter errors, but require correlation and may be incomplete. None alone proves correctness.
2. Use stable service identities such as `tasktrack-squad-cli` with mode `cli` and `tasktrack-test-harness` with mode `test`. The SDK uses `serviceName` and `mode` options; do not rely on unverified `OTEL_SERVICE_NAME` or `OTEL_RESOURCE_ATTRIBUTES` behavior. Keep dev and production separated through explicit configuration and backend/collector resource enrichment supported by the deployment, and verify resulting resource attributes before building dashboards.
3. Aspire runs in one terminal and the Squad process in another. The CLI launcher does not propagate its own environment back to the parent or other shell, so the sender terminal must independently export `OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317`. Traces may appear after export, while periodic metrics may wait for the 30-second reader interval or clean shutdown. Record actual observed names and timing rather than assuming a demo trace.
4. A session identifier on every measurement can create high cardinality; model/agent labels should also be reviewed for deployment scale and privacy. Avoid prompt, issue, title, source, and token values in attributes. Restrict collector/backend access, set retention, review attributes in a test deployment, and filter or redact data before shared storage.

## Quiz Answers

1. A metric: it can aggregate agent failures over time. Traces help investigate individual failures; logs add event details.
2. `OTEL_EXPORTER_OTLP_ENDPOINT`.
3. OTLP/gRPC.
4. Environment variables set in a child process cannot modify its parent shell or another shell. Export the endpoint in the process environment that will run Squad.
5. 30,000 milliseconds (30 seconds).
6. No. It enables shell metrics collection but does not configure an exporter endpoint by itself.
7. No. The bridge emits an event span and ends it immediately; it is not a full long-running agent-task trace.
