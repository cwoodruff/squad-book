# Chapter 4 Solutions

## Exercise Solutions

1. Possible boundaries:
   - **Lead:** Owns scope, architectural decisions, and shared API/UI contracts; does not implement every task by default.
   - **Backend:** Owns `api/src/**` and server-side behavior; does not introduce frameworks or dependencies without approval.
   - **Frontend:** Owns `web/**` and browser interaction; does not unilaterally change API response semantics.
   - **Tester:** Owns test design and regression evidence; does not report a test as passing unless it was run.
   Teams may choose other boundaries, but they should be concrete, complementary, and aligned with the actual code.

2. The current starter uses an in-memory `Map` in `TaskStore` and has no database configuration, schema, migrations, or persistence requirements. A database specialist would have no durable domain to own yet. Revisit the choice if Tasktrack gains a persistent database, migrations, query performance constraints, or a substantial data lifecycle that needs specialist ownership.

3. A human security approver is a person and a routing/approval target; Squad pauses and the user relays the answer. The `security` base role is a curated AI specialist that can be cast and spawned from its charter. `@copilot` is a separate coding-agent integration that acts through GitHub issue assignment and repository instructions, rather than a standard Squad specialist charter.

4. A preset should contain a manifest (`preset.json`) and reusable agent charter directories. The project-specific state it does not capture includes decisions, memory, skills, ceremonies, complete routing rules, casting history, and individual work history. Use `squad export` for a broader team snapshot when that is the goal.

5. Reconcile the agent’s slug/directory, `charter.md`, roster path and status in `.squad/team.md`, any destination references in `.squad/routing.md`, and casting registry/history identity. Check generated capability data as well. Prefer the coordinator or `squad cast` lifecycle to manual partial edits; validate with `squad health` or the appropriate project checks after repair.

## Quiz Answers

1. The charter defines an agent’s role, expertise, ownership, methods, voice, and boundaries. History is that agent’s accumulated cross-session context and learnings.
2. The v1.1.0 CLI reported 21.
3. **Scribe** merges durable decisions/logs; **Ralph** monitors work queues; **Rai** reviews Responsible AI concerns; **Fact Checker** verifies claims and challenges assumptions.
4. Squad pauses and tells the user a human needs to act. The user relays the request externally and later reports the response to Squad; stale reminders may prompt follow-up.
5. No. Presets capture reusable agent charters and roster composition, not the project’s decisions or skills.
6. `usual-suspects`, `oceans-eleven`, and `custom`.
7. `--force` permits overwriting existing same-name agent files during apply. Without it, existing agents are skipped rather than replaced.
