# Chapter 1 Solutions

## Exercise Solutions

1. The Copilot host is the execution and conversational environment; select Squad in Copilot CLI or VS Code to talk to it. The coordinator is the Squad agent that interprets the request and routes work. The `squad` CLI performs setup and operations; for example, initialize with `squad init` or inspect with `squad doctor`.
2. A question about the port is likely a direct answer. An isolated API validation change can be given to one agent because its scope is narrow. An API/UI contract change may benefit from separate implementation or investigation tasks, but first agree on the contract to avoid duplicated or incompatible changes.
3. Tasktrack has API, web UI, and API tests. Potential independent workstreams include UI layout and test coverage around a specified API behavior. The API response shape or task data model is a shared decision before parallel changes that cross the boundary.
4. Project `.squad/` files provide an inspectable, versioned record of team instructions, decisions, and knowledge; a teammate cloning the repository receives the reviewed context. Do not store credentials, tokens, or sensitive personal information there.
