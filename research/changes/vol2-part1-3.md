1. `D/features/copilot-mcp-trust.md` still says Squad injects `--yolo --additional-mcp-config`. Code at v2.0.0 (`copilot-invocation.ts`, #2312) injects only `--additional-mcp-config`.
2. ADR-001 and the spec README (v0.2 rows) say no execution harness or `HarnessAdapter` implementation ships. v2.0.0 ships `ClaudeAgentSdkHarness` and `CopilotSdkHarness`.
3. ADR-002's status is "Proposed", but its provider ships (opt-in) in v2.0.0.
4. `D/scenarios/release-process.md` documents the preview.4 channel setup (`insider` plus `preview` alias, package managers held). The installation and insider-program pages describe `preview` as its own RC channel.
5. `D/features/upstream-inheritance.md` refuses URLs with embedded credentials but its troubleshooting still suggests `https://[PAT]@github.com/...`, and its quick start uses `squad export-config --output`. No such command exists; the command is `squad export --out`.
6. The v2.0.0 Copilot prompt calls Rai and Fact Checker "mandatory support identities" while `squad roster add` makes them opt-in.
7. `D/reference/state-backend-selection.md` still reports #1555 as an open bug, while `resolveSquadState()` passes `paths.teamSquadDir` to `FSStorageProvider` (unchanged since 1.1.0; already noted in Ch 2).
